The current approach is fundamentally unreliable because the position of the pencil (edit) icon changes depending on the length of each contact's nickname. A fixed-coordinate solution will continue to fail. One possible approach is to use the "Nickname" label ("Tên gợi nhớ") as a stable anchor point. Starting from the label position, move the mouse incrementally in small steps to the right while simultaneously performing left-click actions. After each click, use a conditional check to determine whether the nickname text has entered edit mode by counting the number of selected/highlighted characters in the "Nickname" label. If the number of selected characters is greater than zero, this indicates that the pencil icon has been clicked successfully and edit mode has been activated. Once edit mode is confirmed, proceed with the rename operation. Since Zalo automatically highlights the nickname text when the edit icon is clicked successfully, you can reliably use an if-condition to check the number of selected characters in the "Nickname" label and verify whether the click action was successful.
